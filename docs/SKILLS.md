# Danh sách skill Pokémon

*Sinh bằng `python tools/roles/skill_list.py` (sau `tools\role_audit.bat`); đừng sửa tay. Bản lọc / sắp xếp có ảnh: [`docs/skills.html`](skills.html) (mở bằng trình duyệt).*

Mỗi skill một dòng, xếp theo vai trò hiện tại của Pokémon dùng nó (dạng có nhiều sao nhất trong game). **Kiểu**: skill rơi ở đâu (bước data của `data/abilities.json`; skill viết bằng code thì theo probe). **Tung / tại chỗ**: *tung* = dùng từ hàng cuối vẫn trúng (vào mục tiêu, đường thẳng, toàn sàn...), *tại chỗ* = chỉ trúng quanh mình / khi đứng gần (probe: tầm < 4 ô hoặc từ hàng cuối còn < 50% sát thương). **ST/lần**: sát thương một lần dùng lên 7 địch thử (không DEF, không item, chỉ số web), đứng hàng đầu / hàng cuối, số địch trúng trong ngoặc. **PP** web → hiện tại (tự cân bằng), **Sức mạnh** = × sát thương / hồi / khiên của skill (tự cân bằng). **Sửa ở**: dòng định nghĩa skill.
